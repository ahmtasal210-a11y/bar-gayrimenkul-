# Barış Gayrimenkul marka varlıkları

Gönderilen siyah logodan hazırlanan şeffaf PNG kullanılır. Beyaz görünüm CSS brightness/invert ile sağlanır; logo biçimi korunur. Favicon aynı logoyu koyu zeminde beyaz gösterir. Sosyal paylaşım görseli siyah/beyazdır. Hero görselleri kaynak projeden korunmuş temsili görsellerdir; gerçek Karaman mülkü veya ofis fotoğrafı olarak sunulmaz. Yerel fontların lisansı fonts/LICENSE.txt içindedir.
